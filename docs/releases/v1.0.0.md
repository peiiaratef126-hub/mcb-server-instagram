> [!NOTE]

## Executive Overview

MCB Server Instagram reaches its **v1.0.0 production milestone**, providing a self-hosted, enterprise-ready Model Context Protocol (MCP) server for Instagram Professional (Business and Creator) accounts using **official Meta Graph APIs exclusively**.

Over 9 development phases, this project has evolved from core authentication and read tools to a full distributed architecture featuring background Go workers, an isolated zero-token edge webhook gateway, automated AES-256-GCM token encryption, Python-powered media transcoding, AI content optimization with Arabic dialect support, and an embedded glassmorphic web dashboard.

---

## Complete Features Index (All 28 Features)

1. **Feature 1 — Account & Profile Management**: Inspect business profile, followers, media tally, and biography.
2. **Feature 2 — Recent Media Ingestion**: Paginated chronological feed retrieval with like/comment metrics.
3. **Feature 3 — Deep Post Inspection**: Object metadata, permanent URLs, and carousel album children.
4. **Feature 4 — Single Image Publishing**: Feed image publishing with aspect ratio validation (4:5 to 1.91:1) and two-step confirmation.
5. **Feature 5 — Video & Reels Publishing**: Resumable container video uploads and Reels publishing with readiness polling.
6. **Feature 6 — Carousel Album Publishing**: Multi-item albums (2–10 mixed images and videos) with child container lifecycle tracking.
7. **Feature 7 — Comment Inspection**: Threaded comments retrieval with untrusted text data quarantine.
8. **Feature 8 — Comment Reply Dispatch**: Two-step verified comment replying.
9. **Feature 9 — Comment Moderation**: Hide, unhide, or permanently delete comments with two-step confirmation.
10. **Feature 10 — Account-Level Insights**: Aggregate follower demographics, impressions, and daily reach metrics.
11. **Feature 11 — Post-Level Insights**: Granular per-media performance analysis (impressions, saves, video views).
12. **Feature 12 — Mentions & Tags Tracking**: Monitor user tags and caption/comment mentions.
13. **Feature 13 — Hashtag Search & Discovery**: Resolve hashtag strings to Graph IDs and fetch top/recent public posts.
14. **Feature 14 — Instagram Direct Messages**: Enumerate conversation threads, fetch message histories, and dispatch DMs via two-step confirmation.
15. **Feature 15 — Scheduled Publishing Engine**: Schedule posts within Meta's 15m to 75d window or enqueue locally for background dispatch.
16. **Feature 16 — Token Encryption & Auto-Refresh**: AES-256-GCM encryption at rest in PostgreSQL and background daemon with automated 60-day renewal.
17. **Feature 17 — Secret Scrubbing & Structured Logging**: Zero token leakage to stdout or stderr; strict MCP stdio protocol compliance.
18. **Feature 18 — Quota & Rate Limit Management**: Token bucket in-memory limiter (Lite) and atomic database quota tracking with rolling windows (Full).
19. **Feature 19 — Configuration & Environment Validation**: Zod-enforced configuration validation.
20. **Feature 20 — Zero-Token Edge Webhook Gateway**: Standalone edge service running without Instagram access tokens, verifying Meta challenge handshakes and constant-time HMAC SHA-256 signatures.
21. **Feature 21 — Deterministic Auto-Reply Rules**: Safe-by-design rule engine (opt-in only, regex/keyword matching, sliding window rate caps, immutable audit logging).
22. **Feature 22 — AI Caption & Hashtag Optimization**: Claude-assisted generation of targeted hooks, localized hashtags, and CTAs.
23. **Feature 23 — Best Time to Post Analytics**: 7×24 historical engagement heatmap calculating optimal publishing slots.
24. **Feature 24 — Comment Sentiment Analysis**: Multilingual comment classification (positive, neutral, negative, urgent) with Arabic dialect support (Egyptian, Gulf, Levantine, Maghrebi).
25. **Feature 25 — Competitor Analysis (Business Discovery API)**: Query public competitor profiles and media metrics via Meta Business Discovery API.
26. **Feature 26 — Embedded Web Dashboard**: Glassmorphic dark UI at `http://localhost:3000/dashboard` showing live quota gauges, queue status, 7×24 heatmap, and sanitized audit logs.
27. **Feature 27 — Media Upload & Transcoding**: FFmpeg transcoding to Reels specs and Pillow JPEG optimization.
28. **Feature 28 — Multi-Tenant & Multi-Account Architecture**: Schema and container isolation designed for multi-account management.
