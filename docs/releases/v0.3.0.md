## Highlights

MCB Server Instagram v0.3.0 introduces comprehensive **realtime engagement and event-driven automation**, featuring an isolated edge webhook gateway, asynchronous event dispatching, Instagram Direct Messages and Mentions read/write tools, and a deterministic auto-reply engine with immutable audit logging.

### 1. Isolated Edge Webhook Gateway (`services/gateway`)
- **Zero-Token Edge Security**:
  - The internet-facing gateway service runs without holding any Instagram Access Tokens in its environment, memory, or local disk.
  - Requires only `META_APP_SECRET` for HMAC validation and `META_WEBHOOK_VERIFY_TOKEN` for the verification challenge.
- **Strict Edge Defense**:
  - Rejects oversized requests exceeding 256KB with HTTP 413 Payload Too Large.
  - Validates `X-Hub-Signature-256` HMAC-SHA256 headers using constant-time comparison (`crypto/subtle.ConstantTimeCompare`) before any database operation.
  - Rejects forged or missing signatures immediately with HTTP 401/403.
  - Persists verified payloads into `webhook_events` for asynchronous consumption by `core-worker`.

### 2. Core Worker Webhook Event Dispatcher (`services/core-worker`)
- Asynchronous polling loop continuously claims unprocessed webhook events using atomic PostgreSQL state transitions.
- Parses and dispatches typed event models for:
  - `comments`: Comments and replies across owned media.
  - `mentions`: Caption mentions and comment mentions of the business account.
  - `messages`: Incoming direct messages and customer inquiries.

### 3. Engagement & Direct Messaging Tools (`apps/mcp-server`)
- **Mentions & Tags (Feature 12)**:
  - `get_user_tags`: Query media where the account has been tagged by external users.
  - `get_mentions`: Deep inspection of comments and media where the account was mentioned.
  - All text is quarantined with strict UNTRUSTED DATA warnings.
- **Direct Messages (Feature 14)**:
  - `list_conversations`: Browse active direct message conversation threads.
  - `get_conversation_messages`: Retrieve chat message history.
  - `preview_send_dm` & `execute_send_dm`: Two-step write flow with 5-minute single-use cryptographic tokens to dispatch direct messages.

### 4. Rule-Based Auto-Reply Engine (Feature 21)
- **Safe-by-Design Automation**:
  - **OFF by Default**: Requires explicit `AUTO_REPLY_ENABLED=true` configuration.
  - **100% Deterministic**: Pure keyword and regular expression matching. Zero LLM involvement in automated responses to eliminate hallucinations and prompt injections.
  - **Anti-Spam Rate Capping**: Sliding window rate limits per user per rule (default: max 5 replies/hour per user) preventing infinite loops.
  - **Immutable Audit Logging**: Every automated reply is logged in the `audit_logs` table with incoming text, outgoing response, rule ID, and timestamps.

### 5. Webhooks Architecture Guide
- Detailed documentation in [`docs/webhooks.md`](../webhooks.md) for configuring Cloudflare Tunnels, ngrok, and Meta App webhook subscriptions.
