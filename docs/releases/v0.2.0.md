## Highlights

MCB Server Instagram v0.2.0 expands the server capabilities from read/engagement operations into **high-integrity content publishing**, featuring end-to-end media validation, automated FFmpeg transcoding, multi-item carousels, schedule planning, and an asynchronous publishing state machine with guaranteed exactly-once delivery.

### 1. Robust Publishing Tools (Lite & Full Modes)
- `preview_publish_image` & `execute_publish_image` (Feature 4):
  - Validates feed aspect ratios (4:5 to 1.91:1) before creating Graph API containers.
  - Generates single-use cryptographic confirmation tokens with preview summaries.
- `preview_publish_video` & `execute_publish_video` (Feature 5):
  - Supports Instagram Reels and Feed videos.
  - Integrates with Meta's resumable container creation flow.
- `preview_publish_carousel` & `execute_publish_carousel` (Feature 6):
  - Multi-item carousel publishing supporting 2 to 10 images or videos.
  - Automatically sequences child container creation and wait states before publishing the parent container.
- `preview_schedule_post` & `execute_schedule_post` (Feature 15):
  - Validates publication timestamps against Meta Graph API scheduling rules (minimum 20 minutes, maximum 75 days in advance).
  - Integrates seamlessly with worker queue scheduling in Full Mode.

### 2. Media AI Validation & Transcoding (`services/media-ai`)
- **Pillow & FFprobe Validation**:
  - Validates image dimensions, formats (JPEG/PNG), file sizes (<=8MB), and aspect ratio bounds.
  - Validates video codec (H.264), audio codec (AAC), framerates (23–60fps), bitrates (<=25Mbps), and Reels aspect ratios (strictly 9:16).
  - Explicit rejection of invalid aspect ratios, oversized files, or unsupported codecs with actionable remediation error messages.
- **Automated Reels Transcoding**:
  - FFmpeg pipeline (`transcode_to_reels`) converts non-compliant videos to 1080x1920 (9:16), 30fps, H.264 high profile with AAC audio.
- **Image Standardization**:
  - `convert_image_to_jpeg` converts RGBA/PNG assets to JPEG with automated background filling and quality optimization.

### 3. Asynchronous Publishing State Machine (`services/core-worker`)
- **PublishEngine**:
  - Implements the complete Meta publishing lifecycle: `Create Container -> Poll Status (IN_PROGRESS -> FINISHED) -> Publish Container`.
  - Exponential backoff with configurable timeouts and error propagation for Graph API errors (`EXPIRED`, `ERROR`).
- **Zero Double-Posting Guarantee**:
  - Uses PostgreSQL `SELECT ... FOR UPDATE SKIP LOCKED` combined with state machine transition checks.
  - Tested under high concurrency across competing worker instances with 100% verified single-delivery.

### 4. Comprehensive Upload Documentation
- [`docs/media-upload.md`](../media-upload.md): Complete specifications for Meta Graph API v21.0 media hosting, resumable binary upload protocols (`rupload.facebook.com`), and local-to-cloud ingress strategies.
