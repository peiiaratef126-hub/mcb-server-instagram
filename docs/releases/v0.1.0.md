## Highlights

MCB Server Instagram v0.1.0 delivers the complete **Lite Mode** experience: an official Meta Graph API MCP server for Claude Desktop and other MCP clients that requires **zero Docker overhead**, running directly on Node.js/TypeScript.

### 1. Official Meta Graph API Exclusivity
- 100% compliant with Meta Terms of Service.
- Zero reliance on reverse-engineered libraries or scraping.
- Integrates with Meta Graph API v21.0 using Facebook Login for Business.

### 2. Comprehensive Read Tools
- `get_profile_info`: Inspect bio, handle, metrics, and profile metadata.
- `get_recent_posts`: Browse past media with pagination controls.
- `get_post_details`: Inspect captions, media URLs, and carousel child slides.
- `list_comments`: Review audience reactions safely.
- `get_account_insights`: High-level reach, impressions, and engagement metrics.
- `get_post_insights`: Post-specific performance analytics.

### 3. Two-Step Confirmation Security Model
- Write actions cannot be invoked directly by autonomous agent hallucinations.
- `preview_reply_comment` and `preview_modify_comment` return action previews and expiring 5-minute single-use confirmation IDs.
- `execute_reply_comment` and `execute_modify_comment` validate and burn the confirmation ID before dispatching the Graph API mutation.

### 4. Zero-Leak Token Management
- `npm run refresh-token` exchanges your active token for an extended 60-day token and updates `.env` without ever writing tokens to terminal output or logs.

## Getting Started (Lite Mode)

1. Complete manual Meta setup as described in [`docs/meta-setup.md`](../meta-setup.md).
2. Populate `.env` with your `INSTAGRAM_ACCOUNT_ID`, `INSTAGRAM_ACCESS_TOKEN`, `META_APP_ID`, and `META_APP_SECRET`.
3. Build the project:
   ```bash
   npm install
   npm run build
   ```
4. Configure Claude Desktop (`claude_desktop_config.json`):
   ```json
   {
     "mcpServers": {
       "instagram": {
         "command": "node",
         "args": ["/path/to/mcb-server-instagram/apps/mcp-server/dist/index.js"],
         "env": {
           "APP_ENV": "production",
           "RUN_MODE": "lite",
           "INSTAGRAM_ACCOUNT_ID": "YOUR_ACCOUNT_ID",
           "INSTAGRAM_ACCESS_TOKEN": "YOUR_LONG_LIVED_TOKEN"
         }
       }
     }
   }
   ```
